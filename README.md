# ⏱️ Cronômetro do Desaforo

Você precisava contar os segundos.
Eu também precisava. Principalmente os que perdi tentando aprender JavaScript.

O **Cronômetro do Desaforo** marca o tempo enquanto uma versão caricata minha, de topete azul e All Star, espera você terminar com a delicadeza de quem já perdeu a paciência.

## 🙄 Uma amostra do atendimento

O cronômetro não fala. A cara já entrega.

> “Pode ir. Já envelheci três anos esperando você apertar VAI.”

> “Seu tempo está passando. Minha paciência já passou.”

> “Você chama de produtividade. Eu estou aqui contando.”

## 🎮 Como funciona

1. Clique em **VAI!** para começar.
2. Clique em **PAUSAR** para respirar, procrastinar ou fingir que está pensando.
3. Clique em **LIMPAR!** para zerar e guardar o último tempo.
4. Comece de novo. A personagem continuará decepcionada.

## 📚 Sobre o projeto

Este projeto começou nas aulas de React Native do professor **Matheus Fraga**, na Udemy — o mesmo professor superlegal que ensinou o biscoito da sorte e involuntariamente abriu as portas para o desaforo.

Desta vez, a proposta era fazer um cronômetro.

O professor ensinou estado, eventos, intervalos e controle da contagem. Eu acrescentei uma caricatura minha apoiada no relógio, julgando silenciosamente quem demora.

A ilustração foi criada com uma quantidade desnecessária de personalidade.

⏱️ **A base veio da aula. A impaciência é autoral.**
